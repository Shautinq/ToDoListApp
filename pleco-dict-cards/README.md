# БКРС Карточки — короткие определения для Pleco

То же самое, что и `pleco-dict/` (полный БКРС, дамп 2026-08-14,
1 788 096 статей), но определения обрезаны до **одного главного значения**
без примеров и второстепенных смыслов — короткий текст в стиле "сущ.
экран, дисплей" вместо полной многострочной статьи. Сделано специально
для **Multiple-choice тестов во флешкартах**, где нужно быстро сравнить
несколько вариантов ответа, а не разворачивать полный словарь.

Разбит на 9 файлов (≤83 МБ каждый — лимит GitHub 100 МБ на файл).
Части **не нужно склеивать** — каждый `.pqb` работает как отдельный
словарь.

Полный словарь (`pleco-dict/`) остаётся основным для обычного поиска.
Этот словарь — только для карточек.

## Установка (Termux)

```sh
git clone --depth 1 --branch claude/pleco-russian-localization-98kdhg https://github.com/Shautinq/ToDoListApp.git
cp ToDoListApp/pleco-dict-cards/*.pqb ~/storage/downloads/
```

Или, если репозиторий уже склонирован (для `pleco-dict/`):

```sh
cd ~/ToDoListApp && git pull
cp pleco-dict-cards/*.pqb ~/storage/downloads/
```

## В Pleco

1. Settings → Manage Dictionaries → Add User → Add Existing
2. Добавь все 9 файлов `bkrs_short_NN.pqb` по очереди
3. **Flashcards → Search Cards → all cards → Edit → Batch → Remap to
   dictionary** → выбери этот словарь (не полный БКРС) — чтобы карточки
   брали определение отсюда
4. Обычный поиск слов (не карточки) оставь на полном БКРС — там больше
   контекста, примеров и все значения

## Качество обрезки

Прогнана автоматическая проверка на всех 1 788 096 статьях (не выборка):
пустые определения — 0, утечка технических тегов — 0, обрыв текста без
финального пунктуационного якоря — минимален. Известные редкие
ограничения (десятые доли процента, в основном архаичные/редкие
иероглифы): статьи с несколькими грамматическими разделами внутри одной
статьи иногда берут не тот раздел; ссылки "см. N)" на значение внутри той
же статьи не разворачиваются.
