# БКРС — китайско-русский словарь для Pleco

Полный словарь [БКРС](https://bkrs.info) (дамп 2026-08-14), сконвертированный
в формат Pleco (`.pqb`). Всего **1 788 096 статей**, разбит на 9 файлов
(≤93 МБ каждый — жёсткий лимит GitHub 100 МБ на файл).

Части **не нужно склеивать** — каждый `.pqb` файл сам по себе полноценный
словарь. Просто добавь их все в Pleco по очереди.

## Скачать через Termux (Android)

1. Установи Termux (лучше с F-Droid, версия в Play Store устарела).
2. В Termux выполни:

   ```sh
   pkg update -y && pkg install git -y
   termux-setup-storage
   git clone --depth 1 --branch claude/pleco-russian-localization-98kdhg https://github.com/Shautinq/ToDoListApp.git
   cp ToDoListApp/pleco-dict/*.pqb ~/storage/downloads/
   ```

   Это одной командой `git clone` скачает все 9 файлов сразу (~679 МБ),
   затем скопирует их в папку "Загрузки" телефона, откуда их видит Pleco.

## Установка в Pleco

1. Открой Pleco → **Settings** (шестерёнка) → **Manage Dictionaries**.
2. Нажми **Add User** → **Add Existing**.
3. Выбери файл `bkrs_01.pqb` из папки "Загрузки".
4. Повтори шаги 2–3 для всех файлов `bkrs_02.pqb` … `bkrs_09.pqb`.
5. В списке словарей перетащи их (или используй "Move Up") **выше**
   английского словаря — тогда при поиске слова будет показываться
   русский перевод.

Для работы с пользовательскими словарями в Pleco (Android) нужен купленный
add-on **Flashcards** — без него пункт импорта неактивен.

## Проверка

После установки любых 2–3 частей найди в поиске `你好` — должен появиться
русский перевод "привет, здравствуй". Если словарь стоит выше английского
в списке, он и будет показан по умолчанию.
